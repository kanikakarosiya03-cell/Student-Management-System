# 🎓 Student Management System

A Python-based Student Management System designed to manage student and teacher records efficiently through a simple and user-friendly interface.

## 📌 About the Project

This project was developed to practice and apply **Object-Oriented Programming (OOP)** and Python programming concepts in a practical application.

The system provides functionality for managing student and teacher information while storing the data in a structured JSON file.

The **core application logic, functionality, and OOP implementation were developed by me**. I also used AI as a development assistant to improve the user interface and make the application more attractive and user-friendly.

## ✨ Features

- 👨‍🎓 Student management
- 👨‍🏫 Teacher management
- ➕ Add student/teacher records
- 🔍 Search and view records
- ✏️ Update existing information
- 🗑️ Delete records
- 💾 JSON-based data storage
- 🖥️ User-friendly interface
- 🔐 ID/Roll-number based access to records
- 📊 Organized record management
