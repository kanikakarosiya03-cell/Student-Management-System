# Student Management System

A Python-based application for managing student and teacher records through a simple, user-friendly interface. The project uses Object-Oriented Programming (OOP) principles and JSON for data storage.

## About the Project

The Student Management System was developed as a hands-on project to strengthen my understanding of Python and Object-Oriented Programming.

The application allows users to add, view, search, update, and delete student and teacher records. It stores information in a JSON file, making it easier to manage and retrieve records.

I developed the core application logic and implemented the main functionalities myself. I also used AI assistance to improve the user interface and make the application more visually appealing and user-friendly.

## Features

* **Student Management:** Add and manage student records.
* **Teacher Management:** Maintain teacher information.
* **Add Records:** Store new student and teacher details.
* **Search Records:** Find records using an ID or roll number.
* **View Records:** Display stored information.
* **Update Records:** Modify existing details.
* **Delete Records:** Remove records when required.
* **JSON Data Storage:** Store application data in a structured JSON file.
* **Interactive Interface:** Manage records through a user-friendly interface.

## Getting Started

Follow the steps below to run the project locally.

### Prerequisites

* Python 3.x
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kanikakarosiya03-cell/Student-Management-System.git
```

**2. Navigate to the project directory**

```bash
cd Student-Management-System
```

**3. Install Streamlit**

```bash
pip install streamlit
```

**4. Run the application**

```bash
streamlit run app.py
```

*Note: This command assumes that `app.py` is the Streamlit application's entry point.*
